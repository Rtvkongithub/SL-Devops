# Task - 6
# Day 22 Notes

## What is the difference between git add and git commit?

git add moves changes to the staging area.
git commit saves the staged changes permanently in Git history.

------------------------------------------------

## What does the staging area do?

The staging area lets us choose which changes should be included in the next commit.
This helps organize commits instead of saving every change immediately.

------------------------------------------------

## What information does git log show?

It shows the commit history including:
- Commit ID (hash)
- Author
- Date
- Commit message

------------------------------------------------

## What is the .git folder?

The .git folder stores the complete Git repository data, including commits, branches, history, and configuration.

If it is deleted, the project is no longer a Git repository and all version history is lost.

------------------------------------------------

## Difference between Working Directory, Staging Area and Repository

Working Directory:
The files you are currently editing.

Staging Area:
A temporary area where selected changes are prepared before committing.

Repository:
The Git database that permanently stores all commits and project history.
